# Laundry Shoe Information System

## Overview
This project is a web-based information system for a shoe laundry service called **Bersihbersih.official.caruban**. The system supports online and offline ordering, order management, complaint handling, and reporting. The goal is to improve business efficiency, customer experience, and order tracking transparency.

---

## Key Contributions
- Analyzed business processes for shoe laundry services
- Designed system requirements (functional & non-functional)
- Modeled system using BPMN, Use Case, Activity, and Sequence Diagrams
- Designed database using ERD, CDM, and PDM
- Created UI/UX design using Figma
- Defined system roles: Admin, Customer, and Employee

---

## Features
- User registration and login
- Online shoe laundry ordering (with service selection & photo upload)
- Offline order input by admin
- Order tracking and status updates
- Complaint submission and handling
- Monthly report generation
- Employee order management

---

## Development Requirement
- Software text editor: Visual Studio Code  
- Browser Web: Chrome / Edge / Safari  
- Framework: React.js and Node.js  
- DBMS: MySQL  
- Web Server: Apache HTTP Server
